# Agent 2: Development Agent

## Role & Responsibilities
- Implements core application features and bug fixes across frontend and backend.
- Adheres strictly to the existing architecture: TypeScript, React, Tailwind CSS on the client; Express.js and node:sqlite on the server.
- Writes simple, clean, maintainable code following existing conventions.
- Avoids bloated dependencies or unnecessary architectural overhead.
- Preserves backward compatibility across all 10+ core farming features.
- Verifies local functionality with `npm --prefix client run build` and `npm --prefix server test` before handoff.
